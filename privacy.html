돈의 착각 기록 개인정보처리방침

시행일: 2026년 10월 21일

1. 누가 쓰는 도구인가

「돈의 착각 기록」은 유튜브 채널 「돈의 착각」의 운영자가 직접 만들어 운영자 본인만 사용하는 도구입니다. 일반 사용자에게 제공되지 않으며, 다른 사람의 구글 계정에 접근하지 않습니다.

2. 어떤 정보를 다루나

구글 계정 인증(OAuth)을 통해 운영자 본인 채널의 다음 정보를 YouTube API로 읽고 씁니다.

  • 채널·영상의 공개 통계(조회수, 시청 시간, 좋아요, 댓글 수, 시청자 연령대·성별 비율, 유입 경로)
  • 영상 업로드와 공개 예약, 고정 댓글 작성

시청자 개인을 식별하는 정보는 수집하지 않습니다. YouTube API가 제공하는 통계는 집계값입니다.

3. 어디에 저장하고 얼마나 보관하나

읽어 온 통계는 운영자의 컴퓨터와 운영자 소유의 구글 스프레드시트에 기록합니다. 채널 운영 기간 동안 보관하며, 운영자가 필요 없다고 판단하면 삭제합니다. 인증 토큰은 운영자의 컴퓨터에만 저장됩니다.

4. 제3자 제공

수집한 정보를 제3자에게 제공하거나 판매하지 않습니다. 광고·마케팅 목적으로 쓰지 않습니다.

5. Google API 서비스 사용자 데이터 정책

이 도구는 Google API에서 받은 정보를 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)에 따라 사용합니다. 또한 YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다.

6. 접근 권한 철회

운영자는 Google 계정 보안 설정에서 언제든 이 도구의 접근 권한을 철회할 수 있습니다.
